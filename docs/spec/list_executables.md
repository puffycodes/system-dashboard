# List Executables

- List the executable files that exist on the system.
    - Default: limit to local disks
    - Option to include the dynamic libraries
        - Default: off
    - Output Fields:
        - File Name
        - Directory that the File is in
        - File Size
        - File Timestamp
        - File Category (e.g. executables, dynamic libraries, etc.)

- Output Formats:
    - text
    - csv
    - json
    - html
