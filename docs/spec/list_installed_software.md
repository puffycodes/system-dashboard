# List Installed Software

- List the following information about the system
    - Turn on/off with an option (default: on)
    - Host Name
    - IP Addresses
    - Current Timestamp

- List the software that are currently installed on the system.
    - Output fields:
        - Software Name/Description
        - Version Number

- Output formats:
    - text (default)
    - csv
    - json
    - html
