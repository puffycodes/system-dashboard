SYSTEM DASHBOARD (Windows)
==========================

Version @VERSION@

A local web page that shows this machine's host name, IP addresses and
installed software. The software list can be filtered, sorted and
downloaded as text, csv, json or html.

system-dashboard.exe is the whole dashboard in one file, so nothing needs
to be installed. Copy it anywhere and run it.


START
-----

Double-click system-dashboard.exe. The dashboard opens in your default
browser at http://localhost:8080/.

The program isn't code-signed. If Windows SmartScreen warns about it on
first run, choose "More info", then "Run anyway".


STOP
----

Press Ctrl+C in the console window, or close the window.


OPTIONS
-------

Run it from a command prompt or PowerShell to use these:

  -port <n>      Port to listen on (default 8080), e.g. -port 9000
  -open=false    Don't open the browser
  -help          Show the options and exit
  -version       Print the version and exit

If the port is already in use, choose another one with -port.


NOTES
-----

- The dashboard is only reachable from this machine, and it never changes
  anything on it.
